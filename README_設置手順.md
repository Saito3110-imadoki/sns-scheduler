# sns-scheduler 一式（2026-09-03 版）

sns-scheduler リポジトリの中身を、この一式で丸ごと置き換えるためのファイルです。
**ファイルはすべてリポジトリ直下**（サブフォルダを作らない）に置いてください。
ワークフローだけ `.github/workflows/` の下です。

---

## 1. 設置するもの

```
リポジトリ直下/
├─ daily_generator.py     投稿生成（型ローテーション・個人文体・連投スレッド）
├─ poster.py              自動投稿（連投スレッド・リプ周り対応）
├─ analytics.py           メトリクス計測（毎日22時）
├─ report.py              週次・月次レポート
├─ notify.py              LINE通知（共通モジュール）
├─ infographic.py         図解生成
├─ ai_image.py            AIアイキャッチ（既定オフ）
├─ doctor.py              事前チェック
├─ diagnose.py            不調の原因調査
├─ reply_finder.py        リプ周り文案の作成
├─ find_benchmarks.py     手本アカウント候補の抽出
├─ get_ids.py             ID取得ヘルパー
├─ setup_secrets.py       Secrets一括登録
├─ requirements.txt
├─ config.yaml            設定（IMADOKI用に記入済み）
└─ .github/workflows/     ワークフロー9本
```

不要になったファイルがリポジトリに残っている場合は削除して構いません。

---

## 2. Notionに追加するプロパティ（任意・推奨）

無くても動きますが、作ると機能が増えます。

| プロパティ名 | 種類 | 役割 |
|---|---|---|
| 投稿フォーマット | セレクト | どの「型」が伸びたかを学習する。これが無いと実績枠の自動選定が始まりません |
| 返信先URL | URL | リプ周り用。この列がある行はXで対象投稿への返信として配信されます |

---

## 3. 今回の主な変更

**投稿の作り方**
- 5投稿を「実績枠2・検証枠3」に分け、10種類の型から日替わりで割り当て
  （同じ日に同じ型は出ません。連続する日でも並びが変わります）
- 文体を会社アカウントから「中の人」個人の言葉に変更（`content.voice: personal`）
- 連投スレッド形式を追加。箇条書き型も型の一つとして追加

**分析**
- 外部トレンドが取れないときは、自アカウントで伸びた投稿を材料に
  勝ちパターン分析を継続（分析ごと止めない）
- キーワードのニュース検索RSSを代替トレンド源に追加（認証・クレジット不要）
- X APIの402/401/403/429を分類し、対応方法つきでログとLINEに通知

**運用**
- 全ワークフローがレイアウトを自動判定。cheker（サブフォルダ）でも
  各社リポジトリ（直下）でも同じファイルが動きます
- diagnose に「投稿停止の検出」「ステータス別内訳」「未計測投稿の除外」を追加

---

## 4. 設置後の実行順

Actions タブから、この順で実行してください。

1. **Doctor** — 全部✅になるか確認（❌があれば先に解消）
2. **Analytics** — 8月から止まっていた計測を最新化（診断より先に）
3. **Diagnose** — 投稿が止まった原因を確定（エラー？承認待ち？）
4. **Find Benchmarks** — 候補から3件選び `config.yaml` の
   `topics.benchmark_accounts` に記入してコミット
5. **Daily Post Generator** — 下記3点をログで確認
   - `Xトレンド: N件`（0でないこと）
   - `勝ちパターン分析: 完了`（スキップでないこと）
   - `⚠ 分析機能が制限された状態で生成しました` が出ていないこと

## 5. 設定の切り替え（config.yaml）

| 項目 | 既定 | 説明 |
|---|---|---|
| `content.voice` | personal | company にすると従来の会社アカウント文体に戻ります |
| `content.proven_posts` | 2 | 実績枠の本数。残りが検証枠になります |
| `content.formats` | []（全10種） | 使う型を絞りたいときに型名を列挙します |
| `content.auto_approve` | false | true にすると承認なしで自動投稿されます |
| `reply_outreach.enabled` | false | true にするとリプ周りが使えます（文案は必ず承認待ち） |
